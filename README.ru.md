# PowerDNS Web

[English](README.md) | **Русский**

PowerDNS Web — веб-панель для управления DNS-серверами PowerDNS. Она позволяет работать с зонами и записями через браузер, настраивать пересылку запросов в PowerDNS Recursor и просматривать состояние DNS-сервисов.

## Возможности

- Создание и редактирование прямых и обратных DNS-зон.
- Работа с зонами Native, Master и Slave. Записи Slave-зон доступны для просмотра и обновляются с основного сервера.
- Добавление, изменение и удаление DNS-записей с проверкой значений.
- Управление DNSSEC и просмотр ключей зон.
- Управление forward-зонами PowerDNS Recursor, включая корневую зону `.`.
- Просмотр статистики и журналов PowerDNS.
- Учётные записи с ролями администратора и пользователя с доступом только для чтения.
- Русский и английский интерфейс, светлая и тёмная темы.

## Требования

- Debian 12 или новее либо Ubuntu 24.04 или новее, архитектура **amd64 (x86-64)**.
- PowerDNS Authoritative с включённым HTTP API: нужны адрес API и ключ доступа.
- MySQL или MariaDB для учётных записей панели.
- PowerDNS Recursor с настроенным API, если требуется управление пересылкой DNS-запросов.

Установка и обновления выполняются через APT. Устанавливать .NET отдельно не нужно.

PowerDNS и Recursor необходимо настроить отдельно. Установка панели не создаёт базу DNS-зон и не настраивает репликацию между DNS-серверами.

## Установка

### 1. Подключите репозиторий

Выполните на сервере:

```sh
sudo apt update
sudo apt install curl gnupg ca-certificates
sudo install -d -m 0755 /etc/apt/keyrings

curl -fsSL http://repo.medvedev-it.com/keys/medvedev-it-apt.asc | sudo gpg --dearmor -o /etc/apt/keyrings/medvedev-it-apt.gpg
sudo chmod 0644 /etc/apt/keyrings/medvedev-it-apt.gpg

echo "deb [signed-by=/etc/apt/keyrings/medvedev-it-apt.gpg] http://repo.medvedev-it.com/ medvedev-it main" \
| sudo tee /etc/apt/sources.list.d/medvedev-it.list >/dev/null

sudo apt update
```

Если этот репозиторий уже подключён, повторно добавлять его не нужно.

### 2. Установите и настройте панель

```sh
sudo apt install powerdns-web
sudo powerdns-web-setup
```

Мастер настройки предложит:

1. Создать новую локальную базу MariaDB и пользователя для панели либо подключиться к существующей базе.
2. Указать адрес API PowerDNS Authoritative, например `http://127.0.0.1:8081`.
3. Ввести ключ доступа к API.

Для автоматического создания базы необходима работающая локальная MariaDB с доступом администратора через Unix-сокет. При использовании существующей базы заранее подготовьте её адрес, имя, пользователя и пароль.

После успешной настройки служба запускается автоматически. Панель слушает адрес `http://127.0.0.1:5000` на сервере.

### 3. Откройте панель и создайте администратора

Для первого входа можно использовать SSH-туннель. На своём компьютере выполните, заменив `user@server` на пользователя и адрес сервера:

```sh
ssh -L 5000:127.0.0.1:5000 user@server
```

Оставьте SSH-соединение открытым и перейдите в браузере на `http://127.0.0.1:5000`.

При первом входе в новую базу введите желаемые логин и пароль: панель создаст учётную запись администратора. Далее используйте эти данные для входа.

Для постоянного доступа по доменному имени настройте Nginx с HTTPS. Пример конфигурации установлен вместе с пакетом:

```text
/usr/share/doc/powerdns-web/nginx.conf.example
```

В примере замените `dns.example.org` своим доменом. Доступ к панели предоставляйте только администраторам вашей инфраструктуры.

## Начало работы

- В разделе зон добавьте свою DNS-зону и откройте её для работы с записями.
- Для Slave-зоны укажите адреса основных серверов. На стороне PowerDNS заранее настройте разрешения передачи зон.
- Для работы с Recursor укажите адрес и ключ его API в настройках панели и включите поддержку Recursor.
- Дополнительные учётные записи создавайте в разделе пользователей.

## Обновление

```sh
sudo apt update
sudo apt install --only-upgrade powerdns-web
```

Повторно запускать мастер настройки не требуется. При обновлении веб-служба перезапускается, поэтому панель может быть кратковременно недоступна.

Если APT спросит о замене изменённого файла `appsettings.json`, выберите сохранение текущей конфигурации, чтобы оставить свои параметры подключения. Копии настроек перед обновлением сохраняются в `/var/lib/powerdns-web/backups`. Они не заменяют резервную копию баз данных.

## Проверка работы

Состояние службы:

```sh
sudo systemctl status powerdns-web
```

Последние сообщения службы:

```sh
sudo journalctl -u powerdns-web -n 100 --no-pager
```

Если панель не запускается после установки, убедитесь, что мастер `powerdns-web-setup` завершился успешно и база данных доступна. Если зоны не загружаются, проверьте адрес и ключ API PowerDNS, а также доступность API с сервера панели.
